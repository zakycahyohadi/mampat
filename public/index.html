FAQ

Yang sering ditanyakan

Apakah file saya diunggah ke server?

Tidak. Semua alat di Mampat bekerja di dalam browser kamu. File dibaca, diproses, lalu disimpan lagi di perangkatmu sendiri. Tidak ada salinan yang dikirim atau disimpan di tempat lain.

Benar-benar gratis dan tanpa batas?

Ya. Tidak perlu akun, tidak ada kuota harian, dan tidak ada batas ukuran file. Batasnya hanya memori perangkatmu: file ratusan MB biasanya lancar di laptop, di HP prosesnya lebih lama.

Bisa dipakai tanpa internet?

Bisa. Buka Mampat sekali saat online, setelah itu semua alat tersimpan di browser dan tetap jalan walaupun offline.

Di mana file hasil unduhan?

Android: langsung masuk ke folder Download. Buka aplikasi Files (atau File Manager/Dokumen), lalu pilih Download. iPhone (Safari): ketuk Unduh kalau diminta, lalu buka aplikasi File › Telusuri › Unduhan. iPhone, Mampat yang dipasang di layar utama: setelah menekan Simpan, pilih Simpan ke File di lembar Bagikan, lalu pilih folder Unduhan. Laptop: folder Download (Unduhan).

Bagaimana cara memasang Mampat di HP?

Di Chrome Android, tekan "Pasang aplikasi" di atas atau menu ⋮ lalu "Tambahkan ke layar utama". Di iPhone, buka lewat Safari, tekan tombol Bagikan, lalu "Tambahkan ke Layar Utama".

Bisa untuk PDF yang dikunci kata sandi?

Bisa. Mampat akan meminta kata sandinya lalu membuka kuncinya di perangkat kamu; kata sandinya tidak dikirim ke mana pun. PDF yang hanya dikunci izin dibuka otomatis. Hasilnya tidak lagi berkata sandi.
