FAQ

Yang sering ditanyakan

Pilih JPG atau PNG?

JPG lebih kecil dan cocok untuk dokumen berfoto atau untuk dikirim. PNG lebih tajam untuk teks dan garis tipis, tapi ukurannya lebih besar.

Resolusi mana yang sebaiknya dipilih?

72 dpi untuk pratinjau cepat, 150 dpi untuk dibaca di HP atau laptop, 300 dpi untuk dicetak. Makin tinggi, makin besar file dan makin lama prosesnya.

Bagaimana membuka ZIP di HP?

Di Android, buka lewat aplikasi Files. Di iPhone, ketuk file ZIP di aplikasi File dan isinya langsung diekstrak ke folder baru.

Bisa untuk PDF yang dikunci kata sandi?

Bisa. Mampat akan meminta kata sandinya lalu membuka kuncinya di perangkat kamu; kata sandinya tidak dikirim ke mana pun. PDF yang hanya dikunci izin dibuka otomatis. Hasilnya tidak lagi berkata sandi.
